# EMIT

## 게임 소개

**EMIT**은 영단어 TIME을 거꾸로 뒤집은 제목으로 이름처럼 시간을 역행하는 능력을 사용하여 진행되는 액션 플랫포머 게임입니다.

플레이어는 게임만의 독특한 대미지 시스템과 자신을 제외한 모든 적, 오브젝트 등의 시간을 역행하는 능력을 사용하여 다양한 액션을 선보일 수 있습니다.

## 게임 매커니즘

### 1. 공격
적을 이전의 공격과 같은 방향으로 공격하면 적에게 '몰아치기'스택이 쌓입니다.

### 2. 대미지
'몰아치기'의 반대 방향에서 공격하면 스택이 모두 소모되며 적은 더 큰 피해를 입습니다.

### 3. 당기기
전방의 적 하나를 당겨올 수 있습니다. 당기고 있는 적을 공격하면 적을 해당 방향으로 강하게 밀칩니다.

### 4. 전이
다른 적이 강하게 밀친 적에게 맞으면 밀쳐진 적의 '몰아치기' 스택이 전이됩니다.

### 5. 상자
맵 곳곳에 배치된 상자는 '몰아치기'가 더 빠르게 쌓이며, 스택의 전이 또한 가능합니다.

### 6. 역행(EMIT)
플레이어를 제외한 주변의 모든 시간이 역행합니다
이 상태에서 플레이어는 자유롭게 이동할 수 있지만, 적의 행동은 거꾸로 되감깁니다.
'몰아치기'의 상태 또한 거꾸로 되감겨, 반대 방향 공격을 여러번 진행할 수 있습니다.
